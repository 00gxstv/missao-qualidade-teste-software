# Missão Qualidade — Teste de Software

Landing page acadêmica feita somente com HTML e CSS.

## Como abrir

1. Extraia o arquivo ZIP.
2. Abra o arquivo `index.html` em qualquer navegador.
3. Não é necessário instalar programas nem usar internet.

## Conteúdo

- Conceito e importância dos testes de software;
- Casos Virtual Case File e NPfIT;
- Testes unitário, de integração, funcional e de desempenho;
- Quiz interativo de cinco perguntas, feito sem JavaScript;
- Layout responsivo para computador e celular.
